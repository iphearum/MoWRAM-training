# Learning Guides

These classroom guides explain how the Laravel Portfolio Demo was assembled. Start with the Blade portfolio lesson, then add the DataTables management screen.

## Lessons

1. [Build a Static Portfolio Layout in Laravel Blade](build-static-portfolio-with-blade.md)
   
   Convert a static HTML portfolio into a shared Blade layout, reusable partials, routed pages, and public assets.

2. [Add Profile Management with Laravel DataTables](add-profile-management-datatable.md)
   
   Add an AJAX endpoint and a searchable, sortable, paginated profile table using Yajra DataTables.
